Критерий остановки при малом относительном убывании функции

SC — класс, реализующий критерий остановки оптимизатора, когда абсолютный прирост функции относительно значения функции становится мал.

Конструктор(ы)

◆ SC()

SC::SC ( double epsilon,
size_t N )
inline

Конструктор принимающий на вход два параметра критерия остановки: epsilon — точность, N — максимальное число итераций.

Методы

◆ IsSatisfied()

bool SC::IsSatisfied ( const trajectory & t) const
inlineoverridevirtual

Функция SC::IsSatisfied принимает на вход траекторию работы оптимизатора типа trajectory и возвращает true если критерий удовлетворён и false — иначе. Критерий удовлетворён, если число итераций и длина траектории больше 1, а значение (f_{n-1} - f_{n-2}) / f_{n-1} меньше epsilon (n — длина траектории, f_i — значение функции на i-ом шаге оптимизатора), или число итераций превысило N.

Замещает AbstrStopCriteria.
